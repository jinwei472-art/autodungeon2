# AutoDungeon 1.2.0 (Fabric, Minecraft 1.21.11)

Requirements: JDK 21, Gradle 9.x (or newer), internet for the first build.

Build:  double-click build.bat  (or run `gradle build` in this folder)
Output: build/libs/autodungeon-1.2.0.jar   (do NOT use the -sources jar)

Install: put the jar and Fabric API (1.21.11) into .minecraft/mods, start with fabric-loader-1.21.11.

Keys: G = auto mode, K = settings screen, J = continuous right-click.
